Gravity Lab - p5.js version

uni_simulator.pde を p5.js 用 JavaScript に変換したものです。

実行方法:
1. index.html と sketch.js を同じフォルダに置く
2. index.html をブラウザで開く

注意:
p5.js は CDN から読み込むため、初回実行時はインターネット接続が必要です。

操作:
SPACE: 一時停止
R: リセット
+ / -: 重力変更
[ / ]: 時間倍率変更
H: ヘルプ表示切替
X: 全消去
右ドラッグ: カメラ回転
ホイール: ズーム

Processing版にあった Alt+ドラッグによるウィンドウ移動は、ブラウザの制約上除外しています。
また、元のProcessingコードには実際の発射処理が実装されていないため、追加していません。
